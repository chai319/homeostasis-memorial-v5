# 恒常性メモリアルV5

4月の入学式から6月の後夜祭までを過ごす、高校生物の学園恋愛シミュレーション。放課後に誰に会いに行くか、休日に誰とどこへ出かけるかを選びながら、相手の言葉や行動から体内での役割を推理します。

## 遊ぶ

GitHubの **Code → Download ZIP** からダウンロードして展開し、フォルダーの `index.html` をブラウザーで開いてください。Macでは、Python 3 が入っていれば `Macで起動.command` でも起動できます。進行の保存には、同じブラウザーと同じ起動方法を使ってください。

主人公の性別と攻略相手の性別は個別に選べます。攻略対象はV4からの6人と、水守瑞太／瑞葉、糖解アミ、白守頼の計9人。結城つむぎと備汐里は行事に登場します。

[遊び方](遊び方.md)に放課後の手がかりと保存方法があります。立ち絵と衣装を先に見たい方は、ダウンロードしたフォルダーの `立ち絵一覧.html` を開いてください。

## 開発時の確認

リポジトリ直下で、Node.js 22以降を使って実行できます。

```sh
node tests/season.cjs
node tests/player.cjs
node tests/portraits.cjs
node tests/expressions.cjs
```

通しプレイと分岐、画面操作とセーブの再現、立ち絵の呼び出しをそれぞれ検証します。画面操作のテストは模擬DOMを使用します。

新規攻略ルートの脚本原稿は `scenario/` にあります。原稿を編集した後は `python3 scenario/compile-v5-twins.py` と `python3 scenario/compile-v5-extra.py` でゲーム用データを再生成できます。共通行事と休日の寄り道は `v5-pilot.js` に収録しています。
